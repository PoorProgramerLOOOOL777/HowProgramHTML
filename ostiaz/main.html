HTML

Base estructural del contenido

Etiquetas

Permiten organizar títulos, párrafos, listas, imágenes, enlaces y secciones dentro de la página.

Semántica

Elementos como header, main, section y footer ayudan a describir mejor el contenido y la accesibilidad.

Formularios

Los inputs, botones y selects permiten captar información del usuario y crear interacciones reales.

CSS

Estilo, diseño y experiencia visual

Colores y tipografía

Controlas la apariencia con variables, paletas, tamaños y fuentes para mejorar la legibilidad.

Layout

Usas flexbox, grid y responsive design para crear interfaces ordenadas en cualquier pantalla.

Sombras y bordes

Los bordes redondeados, sombras soft y degradados hacen que la interfaz se vea más profesional.

ANIMACIONES

Movimiento que hace más agradable la web

Transiciones

Los cambios suaves al pasar el mouse hacen que cada elemento responda mejor.

Keyframes

Permiten crear movimientos más complejos como entradas, giros y efectos de parpadeo.

Interactive UI

Con animación y hover, cada botón y tarjeta se vuelve más dinámico y moderno.
